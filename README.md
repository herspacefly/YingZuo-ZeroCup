# 影作 · 一幕团圆

**在线体验：[打开《影作》](https://herspacefly.github.io/YingZuo-ZeroCup/)**

《影作·一幕团圆》是一座皮影艺术数字文化馆，把皮影知识与据《劈山救母》原创改编的互动戏放在一起。作品围绕“匠心传成，非遗焕新”展开：你可以先逛展，认识材料、刻制与操演，也可以为沉香备好行装、点亮幕布，陪他走完救母的故事。

## 怎样体验

首页提供快速试演、完整体验、节选导览和自由逛馆。快速试演约90秒，完整模式约23分钟，节选导览约8—10分钟；准备、加载和手动操作按实际体验用时计。

完整体验沿着这条路径展开：

故事缘起 → 制偶 → 调灯 → 练习 → 正式演出 → 留影成果 → 展馆

快速试演在首页独立展开，用默认影偶体验灯影与招手，故事停在华山前。试演独立管理灯位、动作与进度。展馆也可以直接进入，从任意一件展签开始阅读。

### 制偶、调灯与操演

为沉香选择整套配色，或分别调整衣身、袖子和下摆。影偶保留原画刻纹，制偶页可以试提，练习台可以细调姿态。

调灯工坊让影偶固定在幕前，拖动灯具便能观察彩色幕影的偏移与大小变化。二维幕面和三维空间可以切换，正式剧场与快速试演还提供“看看幕后”：画面暂停后，从同一时刻观察影偶、灯光和景片，返回幕前后点击继续接演。

操演支持拖动四肢、牵动身杆和方向键移身，也提供按钮、关节滑块与辅助演出。每次打开网站，各工序首次进入时有可跳过的实操引导，完成后可随时选择“再练一次”。

### 四次选择，五种终章

故事由灯下、上路、山前、山开以后四幕展开。观众依次决定行路愿望、承山约定、开山先后与最后一斧，16种选择组合派生归家、守灯、同行、开放相守、化山五种终章。

片段就绪后即可确认选择。对白、操偶与收杆定场相互衔接，观众可以暂停、跳段、回看或请协助演过。演出进度保存在稳定片段，重新进入剧场时从该片段起点接续。

谢幕后自动打开节目单，以四次选择印记解释终章因果，并保留本场造型。节目单支持下载1600×1200 PNG、本场JSON，以及按本场编排重演。

舞台有沉香、母亲和二郎神三位角色，同屏最多两人。沉香由观众定制和操控，母亲与二郎神的动作随剧情编排。

## 五区七展签

展馆围绕“一张皮、一道刻、一束光、一双手、一出戏”组织内容。17个配图展示位包含12张各异的外部实物或工艺照片，配有图注、出处和观察提示；图册支持放大阅读。

| 展签 | 内容 | 互动体验 |
| --- | --- | --- |
| E01 | 材料、颜色与幕影 | 拖动三维灯具，透过淡化的实体影偶观察清晰彩色幕影 |
| E02 | 刻制与透光 | 在独立莲灯样片上点刻、拖刻，比较八处镂空的刻前刻后效果 |
| E03 | 关节与操演 | 三根杆牵动影偶，结合九关节响应、肩肘细调、标准动作和十部件图册 |
| E04 | 灯影几何 | 调整光线图，结合固定截面与二维画面观察成影关系 |
| E05 | 幕后协作 | 安排操偶、唱念、节拍和灯光，比较职责与节奏对演出的影响 |
| E06 | 剧目来源 | 对照传统剧目资料、故事主线与本作原创改编 |
| E07 | 地方风貌 | 阅读各地实物与资料，认识皮影的地域差异 |

展台使用独立演示状态，参观记录标记实际打开的展签。回到剧场时，作品保留原场节点与选择。知识速览将七件展签的正文、配图和资料链接汇集为一页，每件展签都可通往对应的互动展台。

## 声音与字幕

354条本地中文MP3覆盖完整演出、导览、选择对白、五种终章和成果重演。角色采用分声线配音：

| 角色 | 声线 |
| --- | --- |
| 旁白 | Yunyang |
| 沉香 | Yunxia |
| 母亲 | Xiaoxiao |
| 二郎神 | Yunjian |

中文配音、戏曲音乐与舞台音效各有独立开关。点击页面或按键可以解锁声音；配音播放时，伴奏降至原音量的25%，对白结束后恢复。谢幕先完成对白，再接40秒唱段。完整字幕与台词目录支持阅读、定位和回看。

配音、字幕、动作和空间由同一时钟编排。暂停、幕后观察与返回幕前共同保持当前画面的时间关系。

## 保存与页面入口

作品通过浏览器IndexedDB保存在当前设备。“我的作品”提供JSON导入导出、归档新建和保存重试。自动保存采用串行写入与事务版本检查，配合有效备份、冲突提示和恢复入口，保留造型、灯位、真实选择与稳定剧情进度。

下载的JSON可用于备份，也可导入另一设备或站点地址接续体验。清理本机作品前，保存工具提供导出与确认步骤。

| 入口 | 内容 |
| --- | --- |
| `#/` | 首页、故事缘起、快速试演、继续本场与节选导览 |
| `#/craft` | 制偶与配色 |
| `#/light` | 调灯工坊 |
| `#/practice` | 独立操偶练习 |
| `#/story` | 正式演出 |
| `#/result` | 本场节目单、成果下载与重演 |
| `#/museum`、`#/museum/E01`至`E07` | 展馆目录与七件互动展签 |
| `museum.html` | 皮影知识速览 |
| `#/about`、`credits.html` | 作品介绍与素材致谢 |
| `sitemap.xml` | 站点地图 |

## 运行与构建

使用Node.js **24.x**和npm **12.x**，依赖版本由`package-lock.json`固定。

```powershell
npm ci
npm run dev
```

本地服务地址：[http://127.0.0.1:5173/](http://127.0.0.1:5173/)。

```powershell
npm run build
npm run preview
```

生产预览地址：[http://127.0.0.1:4173/](http://127.0.0.1:4173/)。构建产物位于`dist/`，通过HTTP静态服务器运行，保留目录中的资源相对路径。相对base支持域名根路径和项目子目录部署，配音、音乐、图像与字体随站点提供本地资源。

GitHub Pages通过[部署工作流](https://github.com/herspacefly/YingZuo-ZeroCup/actions/workflows/pages.yml)发布`dist/`，Source选择GitHub Actions。

## 创作与素材来源

故事据传统《劈山救母》原创改编。程序与美术采用AI辅助创作，角色对白使用AI合成中文配音；展馆中的工艺资料、实物照片均附来源链接。

艺术题字使用Ma Shan Zheng，正文、剧情与导航使用基于LXGW WenKai Regular的本地字集，字体许可为OFL。戏曲音乐选用京剧《贵妃醉酒》的京胡器乐与宋若萱唱段节选，采用CC BY 4.0署名方式。

图文出处、音乐署名、字体许可与工具来源汇集于[素材致谢](credits.html)。
