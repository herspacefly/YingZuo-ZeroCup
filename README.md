# 影作 · 一幕团圆

据传统故事《劈山救母》原创交互改编的短戏与数字展馆。已有 **T00工程**、**T03正式数据层**、**T01占位资产**、**T15文字剧情状态机**、**T02产品页面**、**T04双角色成影**、**T07独立三杆练习**、**T05制偶/灯影/开演冻结**与 **T16节点导演/序幕**。制偶可刻纹/着色并预览母亲袖口，灯影可移灯/调距，练习可操偶与演示五动作；剧场可播放自动短场面、同步字幕、暂停切节奏与显式跳序，刷新从当前段暂停重开。图形整场操偶、正式美术和展品互动待后续任务。独立文字排演可走完整/导览两条路径并保存接续。

接手先读 [START_HERE](START_HERE.md)、[项目约定](AGENTS.md)、[当前状态](docs/STATE.md)和[任务账本](docs/tasks.json)。设计依据见[主方案](docs/plans/2026-10-15-yingzuo-design-and-implementation.md)与[叙事稿](docs/content/2026-10-15-yingzuo-story-bible.md)。

## 本地启动

使用 Node.js **24.x** 与 npm。当前实测 Node v24.18.1、npm 12.0.2；依赖以 `package-lock.json` 为准。

```powershell
npm ci
npm run dev
```

默认打开[产品首页](http://127.0.0.1:5173/#/)，其他入口包括[制偶](http://127.0.0.1:5173/#/craft)、[灯影](http://127.0.0.1:5173/#/light)、[展馆目录](http://127.0.0.1:5173/#/museum)、[节目单](http://127.0.0.1:5173/#/result)。原T00首页保留为[独立灯影试作](http://127.0.0.1:5173/study.html)；[运行检查](http://127.0.0.1:5173/probe.html)使用独立探针库；[存档工作台](http://127.0.0.1:5173/project.html)用于正式项目数据、自动保存、恢复与文件检查；[资产检查](http://127.0.0.1:5173/assets.html)显示三角色中性组装、镂空与场景层；[文字排演](http://127.0.0.1:5173/story.html)验证节点、两路径、完成时间与正式存档。无运行时 CDN、远程字体、API 或环境密钥。使用静态本地服务器，不能直接双击 HTML 运行模块。

## 检查与生产预览

```powershell
npm run typecheck
npm test
npm run build
npm run verify:legacy
npx playwright install chromium
npm run test:e2e
npm run verify:state
npm run verify:assets
npm run verify:content
```

`test:e2e` 会启动生产预览服务，占用 4173 端口；请先停止该端口上的其他预览服务。测试含 1440×900 与 390×844 Chromium 视口，手机视口属于模拟。测试截图和失败诊断写到忽略的 `test-results/`。T00 已保留两张[桌面](docs/evidence/t00-desktop.png)／[窄屏](docs/evidence/t00-mobile.png)检查截图。

`verify:assets`检查实际PNG、引用、CSV与哈希；`verify:content`检查18节点图、两条路径、角色/附件/姿态/图层、字幕时间基准与来源/资源引用。开发结构有效时通过。两项加`-- --release`均在当前阶段明确NOT_READY/退出码2；正式美术、文化与许可审定仍待T10。

```powershell
npm run build
npm run preview
```

生产预览默认 <http://127.0.0.1:4173/>，输出目录为 `dist/`。Vite 7.3.7 与 legacy 插件 7.2.1 已锁定；显式构建 IE11 目标，并检查 legacy 产物的 ES5 语法。曾实际发现 Vite 8 组合生成的 legacy 辅助代码含 ES2015 语法，因此本阶段使用已通过产物检查的 7.x 组合。升级工具链后须重做产物和浏览器探针。

**真实 IE11／IE 模式尚未验收。** Chromium 中强制执行 legacy 包只属于产物冒烟检查。后续 T11 需在真实环境补测完整流程、存储及文件下载；不将系统中存在 IE 启动器视作 IE 测试通过。

## 存储探针的边界

- `probe.html` 仅使用 `yingzuo-compat-probe-v1` 数据库，`samples` 仓库保留 current 和 backup；不访问未来正式作品的 `yingzuo-v1`。
- 保存等待整个事务 `oncomplete`，同时写入备份与当前记录。回滚检查在写入成功后中止事务，再核对两条记录。
- 同旧版本的第二写入者会收到冲突反馈并保留页面内灯位。禁止存储时明确未保存，仍可下载测试 JSON。
- study.html灯影试作不自动保存；probe.html的JSON是测试记录，不能作为正式项目导入。

## 产品页面与导航

八个根hash页面和E01—E08目录支持直接打开、返回与刷新，共用一个ProjectStore。地址不推进剧情；无run时需明确开演，已有run只继续。制偶页可保存三段镂空/配色/色槽/纹样，预览真实分件与母亲袖口；完整图形演出仍待导演。未团圆节目单只显示进度，展馆目录不冒记已看完。

“我的作品”中可导入/导出、新建归档、重试保存、取消候选或明确内存继续。保存候选未处理时保留当前页；未知版本/损坏/冲突保留原稿并显示处理入口。工作台在新窗口恢复后，先导出需要保留的页面稿，再明确重新读取。接口与后续页面清理要求见[导航合同](docs/contracts/navigation-v1.md)。

## 二维成影与姿态基础

Canvas现在按真实关节层级、图片pivot、根镜像/缩放和灯影几何投影绘制最多两位演员；颜色区重着色、独立部件镂空、固定角色与前景遮挡共用同一数据帧。必要资源失败给出错误与重试，切页取消旧加载并释放缓存。制偶/灯影/练习显示编辑预览，剧情只读取节点入口与本场冻结造型；没有自动播放或越级推进。

纯数学提供两骨手臂求解、杆连接、letterbox坐标往返及实际姿态/附件包围盒约束。制偶/灯影临时的姿态边界适配不回写Pose，颜色/灯影设置由字段命令保存；练习台操作提交POSE。见[Canvas合同](docs/contracts/canvas-v1.md)。现有几何资源仍为排演占位，未实现半影模糊或精确光学仿真。

## 独立三杆练习

[练习台](http://127.0.0.1:5173/#/practice)提供身杆/左右手杆拖动、可聚焦握柄方向键、方向按钮、关节滑块和镜像/大小调整。挥手、行走、谢幕、举斧和伸手按时间计算，可暂停继续；减少动态时可按250ms步进。失焦、隐藏或长卡顿会暂停，刷新从末次保存姿态默认暂停。

这里只编辑沉香姿态，不启动剧情、改冻结造型或生成录制/成果。失败和内存继续状态保留可导出稿，明确保存才重试磁盘。导演可复用纯动作和有限几何观察，接口见[练习合同](docs/contracts/practice-v1.md)。

## 制偶、灯影与确认开演

制偶页可逐段刻去/还原，键盘和手机可点“完成下一段”；整套或分别给衣身/袖/下摆着色。同纹在母亲袖口预览，旧场保持冻结纹样。身杆可拖动/方向键/按钮试提，此处是临时排演，重置或离页不会改变练习台保存的Pose。

灯影页用滑块、原生方向键和逐步按钮调整灯位/偶幕距离，真实改变几何投影并保存编辑Stage；剧情仍用节点entryStage。明确开演从队列最新外观冻结，默认影偶会标为预设，失败可重试同一候选。已有场可明确归档并保留编辑稿建立新项目，再确认新run，旧场不会被静默替换。接口见[制偶合同](docs/contracts/craft-v1.md)。

## 正式存档工作台

`project.html` 使用正式的 `yingzuo-v1/snapshots`，已有以下检查入口：

- 编辑名称、配色和纹样，500 ms 防抖保存，连续操作最长等待 2 秒；刷新保留项目身份与编辑数据。
- 导出当前项目或未保存的待提交稿；先验证导入文件，再原子归档当前项目并作为新项目接续。导入保留原剧情检查点、runId、决定和冻结造型，默认暂停。
- 新建或恢复上一项目；再次替换归档前可先导出并明确选择。普通保存不改变上一项目。
- 草稿损坏时停下来检查备份；明确恢复后保留损坏原稿，继续编辑、保存和刷新。未知版本和超限原稿保留且停止覆盖。
- 两标签冲突后保留双方版本，暂停自动覆盖；当前未保存稿可导出，明确接管才重读并再次检查版本。

原始记录导出是 `yingzuo-raw-snapshots-v1` 诊断包，使用类型标记保留损坏值，不能当Project文件导入。工作台用于数据接线检查；文字排演通过同一个ProjectStore提交剧情命令，接口以[ProjectV1合同](docs/contracts/project-v1.md)为准。

## 文字排演与剧情接线

story.html提供显式开始、跳过序幕、编辑稿/默认影偶开演、两条路径、文字协助、四秒静候、谢幕和稳定成果摘要。它不提供手动操偶；操作段按明确协助记录，自动分镜不算协助。两模式用同一故事和完成条件；切模式需暂停并重开当前短节点。

推进先保存再应用，失败时保留旧节点和可导出候选，可原样重试/取消/明确内存继续。进入curtain仅写一次完成时间，成果ID由runId派生；刷新默认暂停，不重新选择已保存路线。新项目先归档，既有演出不会被组件重挂载重置。

消费者先读[剧情合同](docs/contracts/story-v1.md)和[导演合同](docs/contracts/director-v1.md)。T16已接NodeScope、绝对时间调度、双缓冲旧帧保留与队列内scope/guard校验；自动场结束才提交检查点，失败可明确重试/取消/仅内存继续。当前静音、几何素材；互动节点和用户谢幕仍停在初始构图，T17再接真实操偶/几何判定/两路整场。文字排演和自动短场面通过不代表完整图形流程或实际演出时长验收。
