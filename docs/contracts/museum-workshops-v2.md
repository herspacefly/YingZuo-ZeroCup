# 展馆实验消费者契约 v2（T35）

公开展签为E01—E07、五个展区。E08已撤下；`ExhibitId`、存档校验仍接受历史E08参观记录，不增加、不丢弃旧记录。未知展签落回目录，不生成空署名展项。外部图册维持12张不同公开照片、来源与未知许可状态；原有4张数字素材转入相应展签，合计17次图像展示，不删除素材文件。

`mountMuseumDemo(host,kind)`按原demo键分派：layers/light进入局部灯影工坊、carving进入独立样片、joints进入关节与部件台。仅接收Project读取冻结外观，不持有Store。生命周期有update/dispose，参观VISIT保存回报不重置局部实验。每次离页清理指针、Three/Canvas、图像监听与迟到异步加载。

灯影固定影偶，只改局部StageConfig的lampX、lampGeometry（version1/depth）；拾取使用现有Three灯具平面。CanvasFrame新增瞬时`shadowColor:'original'`，仅在shadowOnly为true时有效：保留彩色、透明背景，供织幕贴图和二维实验共享；缺省仍沿用既有棕色独立影子。此字段不进入ProjectV1。

镂刻使用独立SVG遮罩和8处样片孔隙。相同孔隙重复点/拖幂等，越界索引无变化；刻前对照不会抹去已经刻下的记录。鼠标/触控及逐刀按钮等价，不写外观patternId或carvedSegments，不复用旧云纹。

幕后合奏的EnsembleScore四项职责分别有enabled/delay；唯一AnimationClock驱动6.4秒短段。动作、字幕、节拍和灯光从同一绝对时间纯采样。1000ms一拍，延后半拍500ms、一拍1000ms。播放及关键帧必须等幕面ready，加载/错误、长间隔、失焦/隐藏暂停；离页取消订阅与时钟。减少动态或动效简化时使用关键帧。幕上方有同步职责状态章，完整设置保留在下方短卡。它不声称固定班社人数，也不合成传统声腔。

署名清理覆盖体验、关于、成果文字及PNG、独立致谢与图册元数据；第三方作者/机构/许可信息保留。静态顶部定位为“皮影艺术 · 数字文化馆”。正文、导航仍常规楷体，艺术标题保留。
