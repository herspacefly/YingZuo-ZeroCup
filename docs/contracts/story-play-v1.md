# T17 图形整场交互接口

日期：2026-10-17。消费story-v1、director-v1、canvas-v1与practice-v1。ProjectV1、18节点、冻结外观及唯一分支均不改版本。T10已接原创皮影风格设计稿及默认静音的可选合成短音；正式审看/听感和实体设备仍另行验收。

## 实际观察与明确参与

`createNodeInteraction(node)`只观察最终受约束的CanvasFrame，返回`observe(frame, elapsedMs, paused, operated)`与`reset()`。读取实际右上臂/前臂包围盒判定挥手、架挡，带附件的实际角色包围盒判定上路，躯干motifPlacement变换后的区域判定寻光，实际右手杆连接点判定伸手。不用整个影偶代替纹样，不用滑块目标值代替最终渲染姿态。

观察校验场景、演员、附件与有限关节；无效帧、暂停、未操作、时间倒退或超过250ms断档清除连续记录。举斧先在限定角度保持半秒，身杆漂移不得超过根坐标.008，之后还须用户真正落手；保持举斧任意久都不会自动落斧。伸手要求实际手点接近，界面还要求本段右肩/右肘真实变化，单纯等待或搬动身体不会替用户完成最后一次伸手。

`projectedInteractionRegion`与`interactionHandPoints`供界面显示同一实际观察范围；金色框为目标，白色框为当前区域。覆盖率为实际投影区域联合bbox与目标的交面积除以目标面积，不是IoU或镂空像素面积。伸手的金色框跟随母亲当前手点。距离及覆盖门槛沿用内容合同，两模式相同。`interactionGoal(node, frame)`只求明确协助的合法目标，不计时、不生成完成证据。

## 输入与唯一时钟

`mountStoryRodControls(panel, stage, port)`只拥有DOM输入及清理，提供render/release/tick/dispose。port读取当前纯帧和允许的杆/灯控，回传临时Pose或灯位/距离；不访问Store，不建RAF或计时器。拖动按CSS像素反投影，保留抓取偏移，匹配活动pointerId/Touch identifier，取消、失焦、离页释放。键盘按住方向键由导演唯一时钟tick推进，原生range保留原生键盘行为。

第一段只开放右手杆；后续开放身杆和右手杆；寻光另开放灯位/距离。纹样在入口距离.2时无法达到35%覆盖，故必须允许身体与距离一起调整，不放宽完成门槛。默认暂停，点“继续操偶”才开放手动输入；操作时间不受自动短场面的targetMs截断。

明确点“帮我演过这一段”后才播放协助，先沿同一几何约束移动，再满足同一观察条件。至少播放3.2秒，提交记录source=assistance。真实条件成立之前暂停会清除连续观察，并从当前姿态重新开始协助片段；成立后的回应/开山等收束阶段保留结果，暂停后继续原阶段。减少动态改为离散视觉阶段，仍经过时钟和门槛，不直接完成节点。超过10秒无法满足条件时报真实错误并暂停。

## 场面、伸手与谢幕

`stagePlayFrame`在纯导演输出上安排回应、透明度、尘幕和山片开合，不写进度。挥手成功后母亲才回应；举斧落手成功后才开山；寻光用真实覆盖渐显母亲并消散尘幕。山片保持闭合时使用半透明排演层，使操偶角色仍可见；远山不透明度.55，避免与母亲固定衣色重合而吞掉衣身轮廓。CanvasFrame.actorOpacity为可选Partial<Record<ActorId,number>>，只允许当前演员ID和有限0—1，未指定默认1；只影响绘制，不改观察几何。透明演员仍预加载部件，避免逐帧切换资源。

伸手完成后的辅助靠近最多移动实际手点.04世界单位（幕宽2%），IK受限后再次校验实际位移。当前手点构图只在同一个mountStoryController生命周期、同projectId/runId的伸手→静候→谢幕→完成之间临时接续，期间模式切换可沿用；离页dispose、刷新、更换作品/run或回到其他节点立即清除。刷新不恢复鼠标轨迹，而用确定的手臂构图重建稳定静候节点。

`reunion-hold`必须播放至少4秒，播满只显示“谢幕”；用户点击才提交COMPLETE_SCENE/source=user并写首次completedAt。谢幕自动短场面完成后到completed，成果ID仍由runId派生；不会提前完成、重复生成时间或新增录制数据。

## 命令、存档与退出

界面只经`submitScopedSceneCommand`提交CHOOSE、真实evidence的COMPLETE_INTERACTION、协助或谢幕。命令和观察入队前深拷贝；执行时同时核对scope token与runId/revision/nodeId。协助还要求至少3000ms的协助播放观察，领域层继续验证暂停、节点与证据。选择必须点两按钮之一，两路都团圆。

进入下一段前先保存。失败保留旧画面与同一候选，重试不重新生成完成时间；取消后可重新确认。memory/error不自动重试磁盘，必须明确确认或仅在本页继续。临时Pose、灯位、观察、协助进度与手点构图都不入Project；刷新、导入、展馆返回和模式切换从已保存稳定节点0ms暂停重建，保留决定与冻结配置。

NodeScope拥有输入、观察所依附的节点、事件与唯一时钟；页面还清理双缓冲舞台、字幕和媒体偏好监听。十次进入/操偶/退出检查旧Canvas清零、应用输入监听回到基线、取消回调不再推进；真实声音仍未接入。
