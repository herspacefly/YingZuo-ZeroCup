# v3叙事、体验顺序与定场放映契约

2026-10-22。接续v1/v2，不改变ProjectV1外层版本。新开演明确传definitionVersion=3，所有消费者经definitionFor选择本场JSON；1/2仍用原文件，4及其他未知版本继续保护。EndingId和十条路径不变。三个角色、只有沉香可控、至多两人同屏继续有效。

v3为36节点、两路线×五终章，每路径21节点。全文4740—4827字符，导览为独立1413—1452字符节选；subtitleTimebase仍为full-target-ms，导览时间映射由subtitlesForMode完成。所有非craft/completed节点minDurationMs=targetMs，字幕从0连续至目标末帧。交互先播对白再开放操偶，选择先播对白再由用户决定；纯reducer也验证这两个门槛。craft确认不等待计时，沿用原冻结事务。全文可展开，导览里也可读本段完整对白。

标称全文节点目标合计1000秒、导览362秒，其中制偶阅读40/18秒可直接确认，因此不能将标称总和写成实测播放时长。操偶、定场放映、暂停、思考另计；实测使用scripts/measure-v3-runtime.mjs，记录原生时钟、明确协助及自动选择，仍不代表体验者时长。

推荐顺序为故事缘起→制偶→调灯→练习→正式演出→留影成果→展馆。ExperienceStep只用于页面呈现，不进入存档。制偶/调灯下一步经durable保存编辑稿；练习启动演出直接走原串行startStory入口，避免旧页flush后迟到跳转。已有演出推荐接续，所有入口仍可自由进入。按钮进入视口时启动柔和动效，两轮结束，减少动态为静态描边，不自动抢焦点或滚屏。首页缘起按钮的滚动由用户点击触发。

## 共用编排采样

createInteractionClip(node,director)只捕获标准入口及冻结造型，不接受手动Pose、时钟或保存接口。sample(progress,time,reducedMotion)供只读成果重演；showcase(time,reducedMotion)供v3即时定场，durationMs为5600/6600/7600毫秒。前600毫秒遮幕定场，其后分别编排招手、行路、架挡、举灯、劈山与伸手。NPC、灯位、山片和空间分镜一起采样；spatial.light与二维lightLevel同步。减少动态使用关键静帧，时间与保存语义不变。

达标时捕获原SceneCommand及SceneObservation，释放输入，禁止再次判定，隐藏两类握柄与目标框。定场只使用标准入口；原有任意手脚、大小、灯位均不带入。唯一动画时钟驱动elapsed，暂停、失焦、离页依原清理路径。放映中可暂停、跳过、从头再看。结束或跳过后只提交捕获的同一命令；失败保留原候选，由Store重试，不能重算完成时间或重复协助标记。标准末帧保留在切幕加载期间。

Resolution、输入状态、放映位姿、镜头与媒体对象均为瞬时数据。刷新只恢复原稳定节点并暂停，不恢复放映时间或鼠标轨迹。v1/v2即时完成保留原时序；只读重演复用相同编排实现，保持原版本台词和片段时长。
