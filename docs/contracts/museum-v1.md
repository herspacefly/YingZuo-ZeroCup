# 五区八展品与临时演示合同（T18）

日期：2026-10-17。消费navigation-v1、ProjectV1、canvas-v1、craft-v1、practice-v1及story-play-v1；不改存档版本、剧情图或编辑稿含义。

## 内容与来源

`src/content/exhibits.json`保存E01—E08，`facts.json`保存20条工艺/剧目资料（culture）、交互示意（model）及本作原创（original）。`museum.ts`提供类型与五区顺序；`museum-outline.ts`从同一数据派生目录，不另维护正文。

每件展签有40—70 Unicode码点的短说明、120—180码点的展开正文、问题、演示类型、替代文字、事实和来源ID。E01—E07各有1—3个来源；E08读取项目真实记录与本人确认的署名，没有外部背书。`validateMuseumContent`接收exhibits/facts/sources三个完整JSON文档，校验准确八件/五区、引用与事实边界；`verify:content`同时检查。结构通过不等于T10正式文化、素材与许可审定。

来源保留原始URL、核验方式、日期及访问状态。C2/C5/C6/C7有官方可读正文；C3/C4原页超时，仅核对官方搜索索引并在页面注明；C1被人机验证阻拦，不作为本轮展签文化事实依据。C6为官方转载的工艺报道，保留原作者。资料引用不授予外部图片/录音复用权，本展馆没有下载外部媒体。

## 导航、参与与保存

`#/museum`展示五区全部目录；`#/museum/E01`至`E08`直接挂载展签，含上一件/下一件、展开说明/来源及返回本场。目录不记录VISIT；实际展签打开后通过`PageContext.edit({type:'VISIT',exhibitId})`记录“来过”，不表示读完、通关或完成故事。已有访问不会重复追加，同一页面按projectId防止重入提交。

普通参观记录沿用串行Store、防抖和事务版本检查。未知版本、恢复、冲突、待提交候选与根操作锁不写参观；error/memory可以保留页面稿，但Store不会自动重试磁盘。界面如实显示未保存及导出入口。没有可用作品时知识和示例仍开放。临时演示不建立另一套存储入口。

本场标记只取`story.castSnapshot.appearance`；没有冻结时清楚标为示例，不拿编辑稿冒充本场造型。E08读取实际节点、路线、造型来源和协助；`reunionSummary`仅对curtain/completed提供团圆节目单，未团圆不显示成果链接。实际创作署名为零组唯一成员张宇翔（SpaceFly），不推测细分分工或其他成员。

## 局部演示接口

`museumPreviewFrame(project|null)`创建可变数据的独立副本，采用默认中性Pose/Stage及冻结或默认外观，绝不读取可编辑Appearance/Pose/Stage作为本场上下文。各演示返回`update(project)`与`dispose()`；以projectId/runId/冻结外观识别作品更换，Store同作品保存回报不重置当前试验。

| 展品 | 已实现的演示 | 与传统事实的边界 |
| --- | --- | --- |
| E01 | 同一Canvas成影与灯/皮料/颜色/幕的四层开合图 | 不模拟皮料、颜料或散射 |
| E02 | 相同外观/姿态/灯位下统一切换三段遮罩未刻/已刻 | 数字前后对比，不是刀法训练 |
| E03 | 十个部件底图、九关节/三杆、右肩与右肘原生滑块 | 数字模型，不是统一传统制偶规格 |
| E04 | 实际灯位/偶幕距离投影、倍率及同一projectPoint的俯视参考光线 | 参考截面宽0.40，图中影宽不是整只影偶bbox，不是完整光学仿真 |
| E05 | 复用wave-v1同一招手的0/600ms两幅静止画面及四张职责卡 | 当前静音，不提供声部试听或固定班社人数 |
| E06 | 皮影剧目记录、京剧梗概、本作原创三栏对照 | 不把剧目/梗概说成完整皮影戏本 |
| E07 | 唐山/江汉平原/华阴三地域文字卡及官方链接 | 无唱腔录音，不宣称流派复原 |
| E08 | 冻结影偶或明确示例、真实参与记录、创作署名与节目单 | 不补写未发生的选择、协助或团圆 |

E01—E05无独立RAF或音频，Canvas复用同一渲染器；试验只存在页面局部，重置/离页即丢弃。E03底图失败显示真实提示；幕面必要图片失败保留已有“重试幕面”，重新加载失败资源。Canvas不可用仍有全文、来源、控件及E04参考图。

## 剧情返回与清理

离开剧场先执行原PageView/NodeScope清理。返回按原run/revision/node、决定和冻结配置，从稳定节点0ms暂停重开；不恢复瞬时杆位、灯位、观察窗口或迟到回调，不变更completedAt/成果ID。浏览知识不依赖通关，也不能推进剧情。

dispose先撤事件再释放Canvas/缓存/迟到图片，清除部件缩略图src及局部SVG；旧输入、加载或resize不能影响新页。十次展馆/剧场往返及实际资源失败/重试纳入浏览器检查。

三维展台由T06后续使用相同E01—E08地址和PageView边界接入；当前不展示未实现的空间按钮。T09已接PNG/只读编排重演，见result-v1.md；E08仍只展示实际本场参与并链接同一结果页。正式艺术/声音留T10。
