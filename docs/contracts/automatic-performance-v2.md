# 剧场自动开演与连续播放契约（T37）

2026-10-26作者明确批准。替代continuous-performance-v1中仅新开演持有首播票据、刷新和返回暂停的规则；景片、字幕、教学隔离与唯一时钟不变。

正式剧场每次挂载，从已有合法场次当前短片段的起点请求自动播放，包含首次开演、刷新和站内返回。票据只存在于当前控制器，绑定projectId/runId/revision/nodeId，不保存时间、票据或播放状态。空剧场仍由作者明确开场；craft只确认行装、terminal只显示成果。旧v1/v2无对白选择不启动时钟；v3及以后选择对白先自动播，结束后等人亲选。

幕面ready且串行durable解锁后一次消费。只有当前可见且有焦点的document可以创建/消费入场播放；控制器创建时即读取hidden/hasFocus并建立监听，不能只依赖之后才发生的blur。后台初始化不播放、不推进、不保存进度；回焦不重建票据。再次进入可见剧场是新入场请求。

正常切章复用准确下一节点的一次票据。用户明确选择、跳过普通片段、确认行装或完成静候确认，可以建立下一章播放意图，即使之前的意图已主动暂停或失焦撤销。v5最终行动的目标须按同一纯resolveEnding规则计算。命令和保存仍验证run/revision/node，票据不能替用户选择、操偶或生成完成证据。

同页暂停、重开、切换节奏、长帧停顿、blur/hidden、资源/保存失败及error/conflict/recovery/unsupported/closed都撤销票据；失败重试不能复活旧播放。迟到素材与旧scope不能消费新节点票据。暂停按当前瞬时时间继续；刷新/重入只从稳定节点起点重新演。

教学副本不请求入场播放或保存正式进度。正常完成/跳过教学归还正式控制器的原播放意图和时钟，退出/失焦/冲突按既有规则保持暂停；不得让教学点击直接提交正式选择。

声音仍由document级StageAudioSession随唯一剧情时钟采样；默认声音意图和浏览器许可独立。浏览器阻止声音时显示原明确开启/重试入口，画面与完整字幕继续。原音频文件、品质、许可与资产不变。

验证包含可见入场/刷新/站内往返、同页暂停/重开/模式、选择/跳段/确认、保存失败重试、延迟素材失焦、初始化前hidden、教学与v1—v4恢复；受控时钟测试不冒充原生完整时长、物理设备或听感。
