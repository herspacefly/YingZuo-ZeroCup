# 启幕、题字、实操引导与跳段契约

2026-10-25，T29—T32。补充 navigation/practice/story-v4，不改变既有四版正文、外层 ProjectV1、资产版本或剧情唯一时钟。

## 页面呈现

启幕为 document 生命周期一次性状态，模块门闩不随 Store 更新或 hash 路由重置。桌面/移动现代入口使用双幅曲面 SVG、2.6 秒错峰收拢；结束发出 `yingzuo:opened`，再允许题字与教学。系统减少动态、装饰关闭或 legacy 入口直接展开。装饰只使用 CSS 时间，不参与导演推进；隐藏/失焦暂停装饰。最多八组莲灯意象，窄屏只显示四组。

真实 HTML 标题保持文本、层级和布局。书法使用本地 OFL 字集；可用时附加 aria-hidden SVG Mask 逐字揭示。首次进入视口播放一次，重放按钮不写作品。尺寸/文字/字体变化重排装饰，不自动重播。移动端不使用水墨滤镜；减少动态、字体失败/超时、缺少 SVG foreignObject 时显示完整 HTML 标题。切换动效后恢复重播入口。

`credits.html` 是独立只读入口，只读取静态素材清单，不创建 ProjectStore 或访问作品库。体验页面保留使用指导、失败反馈和旧版恢复提示；详细素材、字体和库的来源集中到致谢页。公开展馆照片仍显示机构/地域/原页面。

## 隔离演练

`mountGuidedPage` 保留真实 PageView，调用 `suspendForGuide` 暂停时钟/释放输入，将视图暂时脱离 DOM；同一 factory 挂载第二个视图，使用 `ProjectStore.preview` 和隔离 StoragePort。副本不持有真实数据库、下载、路由、声音或通知能力，预览修改只在副本生效。

每次挂载相应页面安排一次入门，等待路由保存、资源就绪、无候选/冲突及启幕结束。制偶换配色、灯影移动灯具、练习四肢再移身；演出先练播放/暂停/实际存在的台词目录，再等到第一个真正开放的操偶阶段。无台词旧节点只教播放/暂停。页面内保存或切段不重复整套教学。再练入口根据当前节点真实能力更新。

成功、跳过或 Escape 后销毁副本并归还真实视图，恢复原姿态、灯位、时间、选择、滚动位置和原播放意图；原操作需正式再做。blur/hidden/离页/保存冲突退出时保持暂停，不恢复过期播放意图，不覆盖新的作品。握柄定位样式由 `cables.css` 独立维护，不依赖已移除的总帮助入口。

GuideSession、遮罩、目标、步骤、播放位姿和相机都不序列化。提示区域以外的操作拦截；保留跳过、Escape、键盘和滑块替代，减少动态使用静态描边。

## 主动跳过当前片段

`SKIP_NODE` 经过原 `runId/revision/nodeId` 守卫、串行 durable 入口和存储 CAS。仅有默认出口的普通对白/操偶/静候片段可跳；选择节点必须明确选择，制偶仍确认冻结造型，终止节点不可跳。跳段停止输入/任务采样，不构造操偶达标或协助证据，不播放定场动画。

`StoryProgress.skippedNodeIds?: StoryNodeId[]` 缺省为空；旧文件缺省时不增补字段。校验要求唯一、属于所选版本与实际路线且在当前节点之前，禁止选择/制偶/终止节点及与 assistedNodeIds 重叠。节目单分别显示亲手操作、协助和主动跳过。成果/重演依旧采用本场版本、路线和结局。

保存失败保留候选与旧稳定节点，重试原命令；重复点击、旧守卫和重试不重复推进，完成时间/成果 ID 继续幂等。显式跳段记录不是操作证据。

## 练习布局与演示

姿态按钮/滑块/朝向/大小/归位/保存位于幕面下方，按身躯、上肢、下肢短卡分组。动作选择与播放位于右侧短卡。启动所选示范动作先取消旧输入和旧动作，采用完整 `defaultPose` 再采样，保留外观与灯光；不继承用户乱拖后的关节、大小和翻向。
