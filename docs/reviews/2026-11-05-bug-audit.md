# 当前代码与用户体验缺陷审查

审查日期：2026-11-05。基准：main `980e134`，使用当前生产包复现。只列已验证缺陷，不包含功能扩展或视觉优化建议。本轮未修改产品代码，未提交或推送修复。

## 已确认问题

### 1. P1：退役旧归档阻断有效作品的归档重开

位置：`src/persistence/storage.ts:246`，`ProjectStorage.replace()`。

复现：draft/backup为当前有效场次，previous-project为真实旧格式场次；到制偶页展开归档重开，勾选“允许替换已有的上一项目”，再点归档重开。

结果：保存状态从saved变成unsupported，提示“这份演出记录已不再支持”，无法开新场。该判断来自上一项目，不是当前作品；现有作品没有被删除，但当前会话会进入受保护状态。

原因：在检查用户的归档替换确认前，代码先对previous-project执行assertSupported；退役旧场与未知未来格式被同样拒绝，即使acknowledgePrevious=true也无法替换。正常从旧版归档后使用当前故事的用户可遇到这个组合。需要区分退役归档和未知未来格式，保留未知格式保护，并覆盖明确同意替换旧归档的路径。

### 2. P2：桌面悬停样式破坏展馆握柄定位

位置：`src/styles/controls.css:36`；定位样式在`src/styles/museum-workshops.css:3`。

复现：默认动态、桌面鼠标，进入E03三杆展项，移到身杆或手杆圆形握柄并拖拽。

结果：通用按钮:hover规则将translate(-50%,-50%)覆盖为translateY(-1px)。生产浏览器计算值从matrix(...,-24,-24)变为matrix(...,0,-1)，48px握柄横移24px、下移23px，导致鼠标命中与拖拽不稳定。原三杆用例在整组和独立复验中均出现握柄无响应；减少动态模式下三杆独立拖动正常。

原因：通用hover选择器排除了.rod-handle和.limb-handle，却未排除.museum-rod-handle。需要保留拖动控件的定位transform。

### 3. P2：节目单提前把尚未执行的终章显示成已发生

位置：`src/features/result/view.ts:83`。

复现：最后选择已作出，但停在reunion-reach或ending-sacrifice-axe，终章动作尚未完成、completedAt仍为null；此时打开节目单。

结果：归家场显示“母亲恢复自由，母子牵手回家”，化山场显示“沉香……永久留作山影……母亲自由生活”。页面下方同时显示当前仍在动作片段，PNG入口隐藏。存档没有被提前推进，错误仅发生在页面的结果叙述。

原因：reunionSummary已经正确判断本场未完成，但后续只要endingFor返回终章定义，就无条件覆写标题与摘要。应区分“已选定终章”与“演出已到成果检查点”。现有未完成成果测试只覆盖无终章选择的早期节点，漏了这个状态。

### 4. P2：音效受阻后的恢复按钮先执行静音

位置：`src/features/story/controller.ts:83`、`:364`。

复现：音效初始化被浏览器拒绝，使状态为blocked；随后允许音频，再点击舞台音效按钮。使用可控的AudioContext拒绝路径和真实浏览器点击复现。

结果：blocked时按钮仍显示“关闭舞台音效”；第一次点击变为muted、意图false，第二次点击才enabled。错误恢复路径无法直接重试。

原因：按钮展示和点击只依据effectsEnabled意图，不依据blocked/error实际状态。需要为失败状态保留明确的启声重试分支，并与document级捕获启声处理一致。

### 5. P2：默认浏览器回归存在失效基线，不能作为无bug验收依据

位置示例：`tests/e2e/art-audio.spec.ts:9`、`tests/e2e/asset-delivery.spec.ts:21`、`tests/e2e/guide-lifecycle.spec.ts:7`、`tests/e2e/presentation-guidance.spec.ts:17`。

默认套件共688项；本次以单worker、最多12个失败的方式执行，结果6通过、12失败、670未执行。九个音效用例在前置条件就要求paused，而当前正确行为是入场playing；其他用例还操作已删除的craft-pattern/刻纹控件，或要求旧来源条数。

另选46项教学/展馆用例，24通过、8失败、14未执行。其中还有1/2与现行1/3步骤冲突、每次入页重新教学与document访问记忆冲突、使用未适配的原始台词时长等问题。三杆拖动失败则已定位到上述真实CSS缺陷；不把所有测试失败都算成产品bug。

这些失败使相应声音生命周期、重试及后续交互断言没有真正执行，必须修正测试基线后才能用全量回归判断修复是否可靠。此前110项定向通过与CI32项通过不等于688项默认套件通过。
