# T09 团圆成果与只读编排重演

依据主方案T09及叙事稿5.2；沿用ProjectV1/reunionSummary、Canvas、导演和冻结构图合同，不新增存档字段。

1. 真实curtain/completed才开放成果，以runId:reunion为固定成果ID；节目单显示母子角色、冻结纹样/配色、已选路线、默认/编辑造型及实际协助片段。未完成只显示进度与继续入口。
2. 1600×1200 PNG采用reunion-hold的确定稳定结束构图、冻结外观与共纹，附本场路线/节目单识别信息；不采集鼠标轨迹或编辑稿。外观与完成时间固定，页面重入/导入同run不产生新成果ID。
3. artifact.ts提供createReunionArtifact(project)，未团圆抛错；返回独立summary/frame副本。mountReunionExporter(host,artifact)异步准备同一Canvas渲染器的1600×1200留影，提供canvas、ready、toBlob()、dispose()；无后台时钟，资源失败可销毁重建，迟到加载/编码离页后拒绝。仅公开这两个文件给root集成。
4. replay.ts提供createReunionReplay(project)，仅消费完整团圆项目副本。返回segments（id/title/durationMs）、durationMs、sample(segmentIndex,elapsedMs,reducedMotion?)，sample含frame/cues/allCues/lightLevel/shotLabel/ended。按唯一已选分支组织intro→craft→…→reunion-hold→curtain的14个节点，不包含另一分支或completed；各操作段用明确程序动作展示，不调用Store/剧情命令，不写原项目。采样函数无DOM/计时器/RAF，冻结外观涵盖制偶前段，不能受后续编辑影响。
5. root结果页沿用现有纸幕/木色样式，先展示留影与真实节目单，再提供下载PNG/可恢复JSON和“按本场编排再演”。重演默认暂停，显式播放、暂停、重开与前后片段，字幕/全文、减少动态及步进可用；唯一animation-clock、Canvas readiness/资源重试、失焦/隐藏/长帧暂停，换作品/离页清理并拒绝旧回调。重演按钮不切成可编辑story或创建新run。
6. 下载只如实报告向浏览器请求；toBlob/null/异常、msToBlob/legacy、下载能力缺失与ObjectURL释放必须可检查。保存失败/内存继续可导出当前有效团圆稿，未知/损坏不可伪造成果。
7. 必要验证：冻结构图/双角色与两路、未团圆拒绝、纯重演时序/副本隔离/所有节点采样可画；实际PNG签名和尺寸、JSON新浏览器导入的同run/完成时间/分支/造型、只读播放/十次退出/旧资源拒绝、失败与legacy、桌面/模拟手机截图和整站回归。完成后记录真实SHA与清理。

分工：artifact独立树只改src/features/result/artifact.ts、exporter.ts及tests/unit/result-artifact.test.ts；replay独立树只改src/story/replay.ts及tests/unit/replay.test.ts。root负责共享入口、UI/样式、下载桥、浏览器检查与中央账本；不改依赖/路由/ProjectV1。
