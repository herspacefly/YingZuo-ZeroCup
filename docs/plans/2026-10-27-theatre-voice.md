# T38 v5 中文分角色配音

作者于 2026-10-27 明确实施：仅 v5，完整/导览、全部合法选择变体、五终章与成果重演；免密钥 edge-tts，旁白 Yunyang、沉香 Yunxia、母亲 Xiaoxiao、二郎神 Yunjian，自然语速优先。2026-10-27 作者试听沉香/母亲短样后要求保持当前声线与自然语速。

## 制作与复现

`node scripts/prepare-voice.mjs` 从原剧本与实际 `presentChoiceDialogue` 提取 354 个 speaker/text/参数唯一项；不是只读取未经选择派生的 JSON。`scripts/generate-voice.py` 使用隔离 Python 环境中的 `edge-tts==7.3.1`，每条原始 MP3 完整解码、ffprobe 测时、SHA-256 后原子写入；失败重试三次并退出非零，检查点与已有清单均可恢复。`node scripts/prepare-voice.mjs --compile` 拒绝缺音/摘要不符，再编译本地目录与时间编排。

不重新压缩原音乐或美术；服务 MP3 原字节直接保留。旁白/母亲 rate=-8%，沉香/二郎神=-5%，pitch 均 +0Hz。没有以改写中文代替正式字幕，也没有捏造 SSML 情绪控制。发音校对关注沉香 chén xiāng、重逢 chóng féng、行装 xíng zhuāng、承山 chéng shān；尚无已证实需强制替换的多音字，保留服务上下文读法。生成工具不是演员或传统唱腔录音。

## 统一时间与生命周期

配音清单每节点、每节奏、每句按所有合法变体的最大 duration+400ms 和原时段较长者分配。纯适配层供领域门槛、导演字幕、定位与只读重演共用；视觉映射到原始动作锚点。首两秒静候保留；谢幕对白后给原 40s 唱段独立尾声。

StageAudioSession 增加独立默认开启人声意图，不持久化。播放回调不能推进剧情。字幕时间为唯一权威；新句/定位按实际偏移播放，不补读旧整句。原生 playing 才降低音乐到原音量的25%，pause/waiting/ended/失败恢复。暂停、失焦、隐藏、资源或保存阻塞、教学与离页撤销旧播放；迟到回调不能复活。v1—v4 无新资源请求与时间改变，ProjectV1 不增字段。

## 验收

核验 16 组合×2 节奏、全部节点/音频和长句不截断；必要单元与宽窄原生媒体 E2E、完整路径旧测试、构建/ES5/资源/内容/账本检查。人耳听感、真实全长和实体设备与功能自动化分开记录，不用“解码成功”冒充试听。

读音单独登记在 `docs/content/voice-v5-pronunciation.md`。运行时音频地址相对页面目录，支持现有相对子目录部署；清单中的绝对路径只标识 public 文件。试听页由 `scripts/voice-review.mjs` 从实际清单整理38条校对项。
