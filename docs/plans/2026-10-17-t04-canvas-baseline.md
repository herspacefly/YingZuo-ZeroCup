# T04 双角色二维成影实施基线

本轮按主方案8.1/8.2、T04和assets-v1实现生产Canvas基础，不改ProjectV1或剧情命令。

选择领域层纯数学加按需绘制Canvas：不引入动画/物理引擎，不复用工程页的中性画法作为运行态。纯数学在独立工作树实现与测试，主集成人负责渲染、资源和产品接线；接口先固定，再合并验证。Three、拖杆/键盘操偶、完整制偶和节点导演分别留T06/T07/T05/T16。

1. 投影采用D=1.2、灯y=0、归一化根位置与世界宽2/高1.5；实现letterbox像素往返与镜像/缩放反算。关节局部层级尊重anchor/restAngle/pivot/bindAngle，IK尊重模板向下骨方向、弯曲符号与限位。边界使用当前所有部件/可见附件变换后的角点。
2. Renderer接actors/stage/sceneLayers/attachments的纯数据帧，最多两角色，固定角色不带编辑Appearance。颜色区按精确标签重着色，原alpha遮罩与独立部件镂空合成后才进入舞台；背景、演员、前景按层序绘制。
3. 资源按当前帧需要加载，复用已加载图与有限纹理缓存；缺必要资源时显示可读错误并清空场面，允许重试。切页释放图像回调、画布、缓存与resize监听，迟到加载不绘制旧页。不新增独立RAF，未来导演通过update驱动。
4. craft接当前编辑稿的双角色静态预览，母亲共享纹样来自对应预览配置；story接已保存节点的冻结角色和初始场景，保持暂停。light/practice先用真实单偶画布替代静态空幕；真实灯控和操偶仍待后续任务，不能展示假按钮或推进完成位。
5. 验证数学关键反例、实际画布像素/固定角色/双角色遮挡/保存刷新、缺图/Canvas失败/迟到加载与十次进出清理。保留宽窄屏截图，构建与legacy检查不冒称真实IE或图形整场已完成。
