# T02 页面与导航实施基线

沿用主方案4/5节、T02与现有数据/剧情合同；不更改故事范围或存档版本。

选择单一HTML页面外壳与hash路由，所有页面共用一个ProjectStore。逐页独立HTML会重复存储与运行态；引入路由框架会增加当前不需要的依赖。工程探针继续独立，原T00首页保留为study.html。

视觉沿用纸/墨/朱/暖金，宋体标题与清楚的正文。宽屏以幕面和侧栏形成主次，手机上下排布。首页用灯幕与山片的静态构图承载标题，正式人物美术留T10；不把排演资源当作最终原画。

实现顺序：

1. 纯hash解析、稳定路由对象、旧入口单次规范化；未知入口回到可读首页。浏览器前进/返回/刷新不新建项目、不推进节点。
2. 建立八页面与五区八展品入口骨架；Store处理外观/路由和显式剧情开始/跳序。展品仅目录不标已读，结果未团圆不给完成成果，P1无分享/录制空入口。
3. 页面接口mount/update/dispose；切页先暂停占位运行态、卸载监听/订阅。保存候选未处理时保留原页面，提供重试/导出/取消/明确内存继续。
4. 静态DOM回退、键盘焦点、错误/保存中/未保存反馈、手机触摸尺寸；正文不暴露内部任务号。
5. 验证路由与生命周期、实际存档/返回/刷新/故障，以及生产modern/legacy入口。截图作为工程视觉基线；不宣称真实IE或图形整场完成。

T02只实现产品骨架与已有能力接线：制偶基础外观选择可保存，完整分件预览/刻纹/开演留T05；自由灯影与操偶先显示明确占位，实际渲染/输入留T04/T07；展签正文与演示留T18，成果PNG/重演留T09。这样每个按钮的现有结果可检查，不假装未实现功能已可操作。
