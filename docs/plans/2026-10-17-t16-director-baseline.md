# T16 节点导演与序幕实施基线

沿用主方案6.2/7.4/8.3/9.2/T16及story-v1，不改ProjectV1或18节点版本。先完成自动短场面、字幕和生命周期，互动/选择/最后伸手仍交T17。

1. 纯时间导演捕获节点entryPoses/entryStage/entrySceneLayers、附件、模式和冻结造型；仅接沉香可选输入，固定角色由合法脚本合成，最多两角。输出纯Canvas帧、字幕、灯幕亮度与分镜标签，无Store/DOM/时钟。
2. 序幕按现有剧本全18秒/导览10秒同比缩时：点灯、母子分离、幕后显杆、制偶引入。二维幕后示意降低前景山片遮挡，能实际看见操偶杆，不冒称Three侧镜头。保持静音，正文来自既有原创字幕；减少动态使用独立场面分镜点，字幕仍按真实逻辑时间。完整台词可展开阅读，不虚构尚无资源的有声演出。
3. 每次挂载/重开/切模式都有新generation与NodeScope token。作用域清事件、RAF、定时、音频和迟到结果，复用T07唯一AnimationClock；隐藏/失焦/超过250ms停顿暂停，不补时间。
4. 播放只运行临时节点时间，不写Pose/Stage。automatic cinematic/curtain到设计时长才通过scope token和run/revision/node双重检查提交；interaction/choice和user activation不自动完成。结束先捕获未暂停观察，再停钟生成一个候选；失败不自动重试，取消可重新确认末帧，memory/error末尾需明确动作才尝试写盘。
5. 明确跳过仅intro→craft，成功后导航制偶；暂停切模式仅SET_MODE，成功从同节点初值重挂并暂停。刷新/路由回来同样暂停重开，不复刻每毫秒。T16不提供绕过操偶的全剧按钮。
6. 节点资源使用待加载与展示两套舞台：旧scope先停止，旧帧/字幕保留到新帧ready；加载失败可重试。新资源ready才替换并释放旧舞台，scope取消后迟到加载不得夺回画面；初始无旧帧时显示真实加载/失败。Renderer仍没有RAF。
7. root负责页面/命令/双缓冲和验收；独立工作树分别实现纯导演、NodeScope与必要单测。验证全节点/两模式/两帧率、字幕映射、冻结/编辑隔离、输入约束、过期命令、失败候选、资源迟到、减少动态及十次切换。真实声音、正式美术/IE、图形全剧和手动可达性不在本轮验收。
