# T07 三杆输入与基础动作实施基线

延续主方案8.2/8.3/T07与canvas-v1，不改ProjectV1/剧情进度。独立practice只操控沉香，直接进入不自动开演、录制或改变既有冻结角色。产品故事页仍等T16/T17导演接入。

采用纯时间动作/有限几何观察、纯杆坐标变换、可清理输入与共享单时钟四层；不用物理引擎，不在Renderer另开RAF。数学动作在独立工作树实施，主Agent负责输入、控制器、Renderer按需快速更新和验收。

1. 身杆/左右手杆采用由真实投影连接点引出的48px DOM握柄，向下/两侧展开并画连线，避免窄屏触控目标重叠；鼠标/Pointer触屏与Touch回退。先扣Canvas/letterbox再逆投影，保留握柄与连接点的抓取偏移，手杆用实际IK，所有输入按当前附件/镜像/缩放的真实bbox约束。指针取消、失焦、隐藏和切页清理捕获与输入。
2. 原生range与方向按钮提供等价操作；手柄可聚焦，用方向键持续移动，松开即停。手杆range改肩/肘角度，限位与原模板一致；调整镜像/缩放重新校边界，不让输入静默控制固定角色。
3. 五动作沿用已保存的稳定ID：wave-v1/walk-v1/bow-v1/raise-axe-v1/reach-v1，按绝对elapsedMs计算。架挡复用手杆与举斧准备姿态，不另造第六个存档ID。选择动作先准备附件，明确播放后才走时钟；暂停保留姿态，继续不补墙钟，重演从当前姿态另起。
4. 一个共享时钟只在有动作/按键时请求RAF，隐藏/blur/超过250ms卡顿均暂停。输入会停止预设相位，用户可手动接管。减少动态时不自动播放连续动作，提供同一动作的逐步预览。
5. 练习姿态自动经串行Store的POSE命令保存，每200ms限频并有末次尾随提交，change/松杆/松键/暂停/结束及时保存。memory/error保护状态下自动路径只更新内存稿，明确保存才重试写盘；不保存RAF、按键、拖动或动作相位。恢复从已保存末姿态默认暂停，冻结剧情/决定和P1空字段不改。冲突/候选/未知格式时暂停控制并允许原稿导出。根导入读文件前以isBusy停止输入并提交旧项目末姿态，ID改变后拒绝旧回调。
6. 必要测试覆盖坐标往返/抓取偏移/越界/手杆限位、60/120Hz时间一致、暂停与长卡顿、真实鼠标/触屏/键盘、保存刷新/故障/冻结剧情隔离、缺图/late加载/十次进出清理。纯观察函数不提交StoryCommand，不把几何值冒称用户完成剧情。
