## 性能与真人体验

- node scripts/inspect-build-budget.mjs只计算生产index.html现代入口与显式modulepreload的gzip JS总量，目标≤200KiB；动态块、图片/字体、CSS不计入该值。输出包括逐文件SHA及范围，不代表首屏可操作时间。
- 冷启动需要分别记录本机和5Mbps/150ms条件下真实可操作时间、首段必要图片/字体≤2MiB、设备与缓存状态，不能用总构建大小替代。
- 既有低档缓冲/纹理≤512及DPR≤1已有检查；十次进出资源计数不证明真实内存长期稳定。真实fps、draw calls≤80仍需测量。
- 持续10秒低于24fps的提示与主动轻量二维已实现，见[frame-rate-v1](../contracts/frame-rate-v1.md)；复用唯一时钟，与单帧>250ms自动暂停分别处理。故事/练习/重演都有受控验证，轻量模式实际释放空间并限制Canvas缓冲，偏好跨当前打开期间的路由/短幕保留。实际设备FPS与改善幅度仍需T13测量。
- 该功能最终402单元、188项相关宽窄屏E2E（含14新增）全通过，build/legacy通过；入口gzip103,597bytes。完整范围、源码/构建指纹与两项已修审查问题见[本轮证据](../evidence/t10-frame-rate-functional-checks.json)，不替代上面的真实设备与性能矩阵。
- T13需至少3位未参与开发者；按叙事稿EMO-01—04记录前30秒动机认知、亲手促成的时刻、分支理解、卡点与谢幕体验，以及真实时长/音量/听感。受控时钟不能代填6—8分钟/约3分钟或真人反馈。
