## 改动

- 首页缘起卡片恢复历史 `960px` 最大宽度并居中，窄屏随容器收缩；保留原文、卡片内容和视觉样式。历史依据为 `journey.css` 自 v3 起的规格，撤销 presentation 层的全宽覆盖。
- 删除桌面按视窗高度限制剧场左栏宽度的规则。幕面铺满原来的左轨道，左边界和右侧台词栏位置保持不变，两栏实际间距回到 `24px`。右侧卡片无需另行扩宽。
- 幕面继续按既有 4:3 投影绘制，Canvas 显示与 backing 比例一致，不用横向 CSS 缩放伪造加宽；1180px 以下保留上下堆叠。
- 将 `journey.css` 纳入 `site.css` 的固定导入顺序，移除 journey 模块的独立样式导入。首轮对比发现独立导入使开发/生产卡片内间距及高度不同，固定顺序后两端一致。
