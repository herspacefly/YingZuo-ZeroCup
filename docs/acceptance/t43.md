# T43 验收：背景横向拉伸与首页白卡对齐

日期：2026-10-28。T42曾将卡片误改为960px居中，并让幕面按比例整体变大；用户截图说明这不符合目标。本轮明确选择为“只拉宽背景，人物保持原比例”。T43替代这两项布局解释，T42历史证据保留。

## 实现

- 首页白卡使用与上方双卡容器相同的可用宽度，左右边界对齐。
- 正式剧场保持现有左边界和加宽后的宽度，恢复加宽前的高度，与右侧台词目录保留24px间距。窄屏仍上下堆叠。
- 幕后装饰背景独立横向绘制至Canvas全宽；其纵向范围不变。人物、前景与操偶坐标继续共用等比世界投影，不通过拉伸整个Canvas改变人物形状。
- 暂停时字幕高度变化也触发Canvas backing及操作线尺寸同步，离页断开ResizeObserver。没有增加播放时钟、持久字段或存档迁移。
