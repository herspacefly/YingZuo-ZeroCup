# T51 门户参赛说明与知识速览验收

2026-11-07。本地实现已完成，未推送部署；线上仍是此前T50发布版本。实施依据为[作者批准方案](../plans/2026-11-07-portal-compliance.md)，本任务按作者本次提供的门户要求审查。

## 实现与符合情况

- README顶部突出公开地址、真实得分点与加分方向，明确自适应1920／1440／720视口宽度、Chrome129、功能库与制作工具用途。没有预设样式库；IndexedDB明确为本机数据库，后端、云端数据库和服务端动态生成仍未实现。
- 新增`museum.html`，Vite开发／构建共用现有五区七展签、知识、配图和来源。正文区分工艺资料、数字示意及本作原创，每签复用一张既有配图及署名／未知许可说明，E06明确不是同名剧目演出照片。完整图册和数字体验由普通链接进入。
- 知识页产物没有JavaScript引导，不启动Store、音频或Three.js；目录、资料展开与互动入口无需JavaScript可用。首页及展馆目录提供速览入口；评审信息仅在README。
- 首页、速览与致谢设置准确title、description、canonical，站点地图仅列三个真实页面地址。保留互动hash路由，不将SEO补强表述为已收录或已获得加分。
- E01素材首载／重试显示等待及忙碌状态，保留失败反馈、二维回退、重试三维与离页清理。原位清理E01分层、E02衣纹、E06旧剧本及终章选择旧说明；E05／E07摘要兼顾静态和互动阅读。

## 发现、修正与分轮证据

知识页首轮慢网探针发现CSS下载前图片按原宽度撑宽，新增基础body／main／img内联样式后消除。Chrome129保留42条分轮记录，包含12条探针假设失败及说明、1条已修产品缺陷，最终按28个唯一场景的最新结果计数，不声称一次全绿。

部署检查首轮46／48通过；两组Playwright命令共用了默认临时输出目录，导致跟踪文件ENOENT和下载取消。没有修改应用或放宽断言，隔离输出目录后，仅两项受影响用例2／2复验通过。之后未重跑未筛选全套。
